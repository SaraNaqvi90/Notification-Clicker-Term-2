## Notification Clicker

This is a small project I made to practice JavaScript, UI updates, and basic event handling.  
The idea is simple — every time you click the button, the app updates the count and shows it on the screen.

I built this to get more comfortable with linking HTML and JS, updating elements on the page, and making the UI look a little cleaner.

## What this project does
- Shows a button you can click.
- Increases the notification count every time you click.
- Updates the number on the screen instantly.
- Keeps the interface simple and easy to understand.

## Why I made it
Just to practice!  
I wanted a small, manageable project where I could try improving the UI and also play around with JavaScript functions and DOM manipulation.

## Files in this project
- **index.html** — the structure of the page.
- **app.js** — the logic that updates the counter and the UI.

## How to try it out
Just open index.html in any browser and click the button.
